향후 게임 통합 계약 (설계, 구현 없음)

독립 S03 씬은 실제 PlayerController와 전투 시스템에 의존하지 않는다.
게임 연결이 필요할 때 이 폴더에 새 Adapter를 구현한다.

입력
- 기존 PlayerController.AcquireControlLock(owner)/ReleaseControlLock(owner)를
  이용한다. 동일 Adapter 인스턴스를 소유자로 사용하고 획득/해제를 짝짓는다.
- DirectionSequence.inputComponents는 빈 배열로 유지하여 기존 Behaviour
  enabled 상태 복원 방식과 공용 입력 잠금을 동시에 사용하지 않는다.
- onStarted에서 획득, onCompleted/onCancelled 및 Adapter.OnDisable에서 해제.
- 정상 완료와 Cancel을 구분하며 전역 SetMovementEnabled(true) 호출을 피한다.
- 대화/인벤토리/다른 연출의 잠금이 유지되는지 통합 시 검증한다.

카메라
- 독립 테스트 씬에는 Camera/AudioListener를 각각 하나만 둔다.
- 게임 통합 프리팹에는 추가 AudioListener/Main Camera를 넣지 않는다.
- 별도 CinemachineCamera를 DirectionSequence에 연결한다.
- 기존 구현은 priority 100을 쓰므로 다른 카메라와의 우선순위를 검토한다.

이벤트
- DirectionSequence.Play/Cancel을 진입점으로 사용한다.
- onTransitionCovered는 백색 덮임 시점. 위치 이동 이벤트를 연결할 수 있다.
- 비동기 씬 로딩 완료를 기다리는 기능은 현재 없다.
- SceneManager.LoadScene 연결만으로 완성하지 않는다. 로딩 대기와 객체 수명,
  취소/실패 경로를 먼저 설계하고 검증한다.
- DirectionSequence는 static owner로 동시 실행을 제한하므로 중첩 연출 금지.

효과 및 오디오
- DirectionScreen overlay와 DirectionVolume을 연출 소유 객체로 둔다.
- 효과 종료/취소 때 Clear/ResetEffects를 호출한다.
- 기존 무기 AudioSource 소리를 새 연출에서 중복 재생하지 않는다.
- DirectionAudio는 MixerGroup 연결 코드는 있으나 실제 Mixer는 아직 없다.
- 기존 오디오 라우팅은 바꾸지 않고 새 소스에만 연출 Mixer를 연결한다.

S03 독립 연출 테스트

2026-10-28 시네마틱 개선
- 기존 씬/프리팹/Timeline/Signal GUID를 유지한다. 새 중복 테스트 씬을 만들지 않는다.
- 개선 적용: Capstone > Direction > S03 Workspace > Upgrade existing cinematic.
- Generate isolated workbench도 기존 씬이 있으면 같은 업그레이드를 수행한다.
- 가장 최근 결과 열기: 같은 메뉴의 Open latest workbench.

제작 범위
집 현관 blockout + 테스트 캡슐 플레이어 + 실제 복싱 링 에셋.
완성된 가정집/인체 애니메이션/관중 환호를 포함하는 최종 아트 씬은 아님.
S03Prototype의 S03FirstPersonPlayer를 3인칭 카메라 리그와 함께 재사용하며
기존 게임 PlayerController와 전투 시스템을 시험 씬에 복제하지 않는다.

생성 메뉴
1. Unity 6000.3.21f1에서 이 프로젝트를 연다.
2. Console 컴파일 오류가 없는지 확인한다.
3. Capstone > Direction > S03 Workspace > Generate isolated workbench.
   단축키: Ctrl+Shift+F9. 메뉴가 없으면 새 스크립트 임포트를 기다린다.
4. 메뉴가 여전히 없으면 생성 스크립트 Reimport 후 Editor를 정상 재시작한다.
   기존 씬의 의도하지 않은 변경을 저장하지 않는다.
5. Capstone > Direction > S03 Workspace > Open latest workbench를 누르거나
   Scenes/S03_Workbench_<UTC시간>.unity를 Project 창에서 더블 클릭한다.
   생성 메뉴는 기존 씬을 닫지 않으며 새 씬은 저장 후 닫아 둔다.
6. Hierarchy에 생성한 S03 씬 하나만 로드되어 있는지 확인한다.
   다른 씬이 함께 있으면 테스트 리그가 Play 시 스스로 비활성화된다.

생성되는 에셋 (모두 이 S03 폴더 아래, 기존 경로 덮어쓰기 없음)
- Scenes/S03_Workbench_<시간>.unity
- Prefabs/S03_TestRig_<시간>.prefab (환경을 포함한 테스트 전체 리그)
- Timelines/S03_ArenaArrival_<시간>.playable (3초 Signal Track)
- Timelines/StartArenaShot_<시간>.signal, EndArenaShot_<시간>.signal
- Materials/<시간>이 포함된 집/바닥/문/테스트 인체/복싱 링 전용 재질
- Materials/S03_Cinematic_*.mat, S03_Reused_*.mat, S03_CinematicProfile.asset
원본 에셋 메시·텍스처·음원은 원래 위치에서 참조한다.
복싱 링 재질은 새 Material 인스턴스를 에셋으로 저장하여 사용한다.
최초 생성에만 새 타임스탬프를 사용하며, 이후 실행은 기존 결과를 개선한다.
업그레이드는 이 도구가 소유한 실내 구조/카메라 설정을 갱신한다.
씬에 추가한 별도 오브젝트는 유지하지만 해당 관리 영역의 수동 편집은 먼저 백업한다.

Play 테스트
1. Play 버튼을 누르고 Game 화면 안을 클릭한다.
2. WASD로 이동, 마우스로 시점을 조절한다. 시작 방향 앞쪽이 현관문이다.
3. 문 가까이 가면 [E] Open door가 나타난다. E를 누른다.
4. 조작 잠금 -> 문 열림/문 소리 -> 현재 화면 포즈에서 정면 Dolly-In ->
   약 3초 동안 문 발광/조명/URP Bloom·Exposure와 백색 opacity가 함께 증가 ->
   완전 백색 시점에만 경기장 이동/조명 변경 -> 군중음 1.5초 fade-in ->
   백색 1.8초 복귀와 3초 Timeline pan -> 0.85초 Ease In/Out로 3인칭 복귀.
5. 화면의 S03 COMPLETE와 이동/시점 복귀를 확인한다.
6. Esc는 컷신 취소 또는 커서 해제. Game 클릭으로 커서를 다시 잡는다.
7. 문은 한 번만 열리는 기존 프로토타입 동작을 유지한다. 재시험은 Play를
   정지한 뒤 다시 Play한다. E 연타로 여러 연출이 겹치지 않아야 한다.
8. Console에서 오류/예외, AudioListener 중복 경고를 확인한다.

오디오
- 문: door_creak_short_01.wav (후보, 청취 적합성 확인 필요).
- 경기장: background_crowd_people_chatter_loop_01.wav (임시 웅성거림).
- 가정집 환경음은 확보된 음원이 없어 기본값이 비어 있다.
  S03_DirectionRoot > S03SceneBridge > Home Ambience에 별도 허가된 실제
  실내 room tone AudioClip을 넣으면 Ambient 루프 -> 문 열림 때 fade-out ->
  백색 덮임 뒤 경기장 Ambient 루프 fade-in 경로를 사용한다.
- 실제 스포츠 관중 환호, 박수, 대규모 경기장 room tone은 후속 리소스 필요.
- Mixer는 필수 의존성이 아니며 기존 DirectionAudio source gain을 사용한다.
  이번 단계에서 원본 음원 import 설정/기존 오디오 라우팅은 변경하지 않는다.

연출 편집
- 문 지속시간: FrontDoorHinge > S03DoorInteraction > Open Duration.
- 문 카메라 시작은 실제 출력 카메라에서 캡처하므로 CM_DoorAndArena의
  Edit 모드 Transform을 옆으로 옮겨도 45도 고정 샷으로 사용하지 않는다.
- S03_DirectionRoot > S03SceneBridge: White Build Duration=3,
  Reveal Duration=1.8, Overall Timeout=14, White Curve로 덮임 조정.
- Environment/Home_Blockout/S03_DoorwayLight/DoorFocus 및 DoorDollyEnd:
  문 목표와 Dolly 도착점. 이동/회전은 Cubic Bezier와 SmoothStep으로 보간.
- 도착 위치: ArenaArrival. 경기장 샷: ArenaShotStart/End/ArenaLookTarget.
- Timeline: S03_DirectionRoot의 PlayableDirector 선택 후 Window >
  Sequencing > Timeline. Signal Track은 경기장 카메라 pan 시작/종료 담당.
- S03SceneBridge가 긴 백색 증가를 소유하며 완전 덮임 뒤 기존 DirectionSequence의
  Timeline/오디오/Signal/완료·취소 경로를 호출한다. 고정된 공통 fade만 임시 우회하고
  DirectionScreen 참조는 완료/취소/예외 때 항상 되돌린다.
  긴 reveal은 기존 DirectionScreen.Fade를 사용한다. Timeline에서 중복 fade 금지.
- 백색 덮임 검사 실패 시 위치 이동을 취소한다.
- URP Bloom/ColorAdjustments/ACES는 S03_CinematicProfile.asset만 사용한다.
  Play에서 profile 인스턴스를 복제하여 animate하고 종료/취소 시 노출을 복원한다.
  공유 URP Asset/Renderer와 다른 Volume Profile은 수정하지 않는다.
- 경기장: 원본 Crowd Area와 Complete Roof 메시 재사용, S03 전용 외벽/천장/
  기둥/단차 갤러리/통로/스폿 및 보조광. 합본 Crowd area with props는 조사 후
  이동 통로를 가리는 낮은 소품이 있어 전체 배치 대신 뒤쪽 건축 메시와 양측
  Crowd_Chair01/Crowd_Chair002 좌석을 분리해 재사용한다.

통합 경계
- 이 프리팹은 테스트 환경 전체를 포함하므로 기존 게임 씬에 그대로 넣지 않는다.
- 후속 통합 때 필요한 연출 객체를 별도 검토하고 기존 Main Camera/Brain을 사용한다.
- S03ControlLockAdapter.Game Player에 기존 PlayerController를 연결하면
  AcquireControlLock(this)/ReleaseControlLock(this)를 사용한다.
- DirectionSequence.Input Components는 비워 두어 enabled 토글과 잠금을
  동시에 사용하지 않는다. 다른 시스템의 잠금을 임의로 해제하지 않는다.
- 현재 TransferWhileCovered는 S03FirstPersonPlayer의 같은 씬 내 Teleport용이다.
  실제 게임 플레이어 이동/비동기 LoadScene을 연결하는 Adapter는 후속 작업이다.
  기존 게임 씬을 수정하거나 Production 통합 완료로 취급하지 않는다.

검증 범위
Unity 6000.3.21f1 배치 생성 및 실제 Play 정상 완료/취소 검증 통과.

# S07 — 시상식에서 침실 각성까지

독립 기능 프로토타입입니다. 최종 손 애니메이션·군번줄·권총·전장 아트·사운드가 아닙니다.

## Unity에서 실행

1. Unity 6000.3.21f1로 프로젝트를 열고 컴파일과 임포트가 끝날 때까지 기다립니다.
2. 저장하지 않은 다른 씬이 있다면 먼저 직접 저장 여부를 결정합니다. S07 도구는 다른 씬을 자동 저장하거나 변경을 버리지 않습니다.
3. 메뉴 **Capstone → Direction → S07 Workspace → Open test scene**을 클릭합니다.
4. 열린 씬은 `Assets/Capstone/Direction/Workspace/Sequences/S07/Scenes/S07_AwardMemory.unity`입니다.
5. 상단 **▶ Play**를 누릅니다. 임시 2등 데이터가 자동 주입되어 바로 1인칭 시네마틱이 시작됩니다.
6. Game 화면을 선택한 상태로 시상식 → 두통 → 눈 감김 → 군번줄 → 전장 → 침실을 확인합니다. 약 29초 분량입니다. Editor가 오래 멈추면 50초 실시간 감시 타이머가 안전하게 취소합니다.
7. **X**로 중간 취소합니다. 취소 후 **E**로 다시 시작할 수 있습니다. 정상 완료 후에는 중복 실행을 막으므로 Play 종료 후 다시 진입합니다.
8. 정상 완료하면 침실 위치에서 기존 3인칭 테스트 카메라와 조작 잠금이 복구됩니다. 포인터가 해제된 경우 Game 화면을 한 번 클릭해 기존 테스트 플레이어의 WASD·마우스 조작을 다시 받으세요. 다음 게임 씬을 자동으로 불러오지는 않습니다.
9. 마우스가 갇히면 Esc로 포인터를 해제합니다. Play 종료는 상단 버튼 또는 **Ctrl+P**입니다.

## 주요 관찰 지점

- 왼손 은메달과 오른손 머리 짚기
- 오른쪽 → 왼쪽 → 오른쪽 고개 흐름
- 화면 전체가 검정인 동안에만 메달·군번줄·전장 배경 교체
- 눈을 뜬 뒤 같은 왼손에서 군번줄 확인
- 왼쪽 아래에서 정면으로 일어나며 오른손의 비발사 권총 확인
- 정면 전장 약 8초: 폐허, 연기/먼지, 쓰러진 전우를 상징하는 유니폼 블록아웃
- 이명과 검정 전환 후 침실 호흡·각성

## 자동 검사 실행

Play를 종료하고 **Capstone → Direction → S07 Workspace → Run Play validation**을 클릭합니다. 검증이 끝나면 Play가 종료되며 Console에 `S07_VALIDATION_PASS` 또는 `S07_VALIDATION_FAIL`이 기록됩니다. 검사는 정상 실행과 여러 취소·오류 경로를 연속 실행하므로 약 1~2분이 걸릴 수 있습니다.

`S07_EXPECTED_SWAP_FAULT`와 watchdog 경고는 복구를 확인하기 위해 검사에서 의도적으로 주입합니다. 일반 실행에서는 해당 오류를 주입하지 않습니다. 상세 결과와 실제 검증 범위는 VALIDATION.md를 참고하세요.

## 파일이 없는 새 체크아웃에서 생성

**Capstone → Direction → S07 Workspace → Generate first prototype**을 클릭합니다. AssetDatabase/PrefabUtility로 S07 폴더 안에만 생성합니다. 이미 테스트 씬이 있으면 기존 결과를 덮어쓰거나 중복 생성하지 않고 열기만 합니다. 생성 파일과 `.meta`를 함께 보존하세요.
